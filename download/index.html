Installing the APK

Download the correct APK for your device and follow Android's installation prompts. If prompted, allow installation from the browser or file manager you used to open it.

Updating Wazabanga

Wazabanga TV checks for newer versions online. When an update is offered, follow Android's installation prompts to install it over your existing TV app without uninstalling. You can also download the latest APK here. TV and Mobile / Tablet use separate releases.
